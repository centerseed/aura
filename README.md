# SAM System (Stability-first Attention Management)

這是一個專為創業者設計的「不失控」營運管理系統。

## 📁 專案結構 (Project Layout)

- **`/docs`**: 系統所有相關文件（規格、架構、命名規範、Agent 設計）。
- **`/backend`**: FastAPI 後端實作 (Clean Architecture)。
- **`/frontend`**: Next.js 前端實作（儀表板）。
- **`/tests`**: 全域測試與整合測試。
