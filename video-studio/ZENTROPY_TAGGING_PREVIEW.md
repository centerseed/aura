## 🎨 設計元素

### 配色方案

| 元素 | 顏色 | 用途 |
|------|------|------|
| 背景 | `#0f172a` (slate-900) | 深色專業感 |
| Logo | `#3b82f6` (blue-500) | Zentropy 品牌色 |
| 輸入框 | `#1e293b` (slate-800) | 區隔輸入內容 |
| Entity 標籤 | `#8b5cf6` (violet-500) | 實體識別 |
| Status 標籤 | `#10b981` (green-500) | 狀態標記 |
| Type 標籤 | `#f59e0b` (amber-500) | 類型分類 |
| Priority 標籤 | `#ef4444` (red-500) | 優先級標示 |

### 動畫效果

1. **打字機效果** (0-2s)
   - 文字逐字顯示
   - 閃爍游標
   - Spring 彈跳進入

2. **加載動畫** (2-4s)
   - 旋轉圓圈
   - 藍色光暈脈動
   - 「分析中」文字動態點點點

3. **標籤彈跳** (4-8s)
   - Spring 物理彈簧效果
   - 每個標籤延遲 0.7 秒
   - Scale 從 0 到 1
   - Opacity 淡入

4. **光暈效果** (全程)
   - 每個標籤都有對應顏色的陰影
   - `box-shadow: 0 8px 32px [color]40`
