## 行銷角度：產品盲點分析

### Brain Dump 影片相關發現

#### 正面（影片可大力展示）
1. **真的只要打字就好** — 輸入框極簡，沒有任何欄位要填
2. **AI 分類路徑完整** — 自動產出 Area/Product/Topic 三層分類
3. **子任務自動拆解** — "報價單+簡報+會議室" 被正確拆為 3 個 sub-items
4. **截止日自動設定** — "下週三" 被解析為 03/25
5. **可連續輸入** — 完成後不會關閉，可繼續倒更多東西
6. **多模態輸入** — 有麥克風和相機按鈕

#### 盲點/斷點
1. **AI 結果缺乏視覺衝擊** — 結果卡片只是純文字，沒有明顯的「前後對比」感。用戶看不到「混亂→有序」的轉變。影片需要自己補這個敘事。
2. **沒有動畫/loading 回饋** — AI 處理太快（或截圖無法捕捉），用戶可能不覺得 AI 做了什麼事。影片應放大 spinner 時間來強調「AI 正在分析」。
3. **圖片輸入未實測** — 有相機按鈕，但模擬器上無法驗證拍照→辨識的完整流程。影片如果要展示圖片輸入，需要確認功能是否真的可用。
4. **身份地圖的角色不明確** — 「財務/個人/事業」三個 chip 在空白狀態下沒有被選中，用戶可能不知道這是什麼。但其實選不選都可以，AI 會自動歸類。這個設計意圖可能需要在影片中被更好地說明。
5. **首次使用有 consent dialog** — 在用戶最興奮的「第一次體驗」時被打斷。影片應跳過這步。

### AI 排程影片相關發現

#### 正面
1. **今日計畫已存在** — 首頁有「今日計畫」區塊，含可用/已排時間、任務列表
2. **AI Coach briefing** — 「早安，今日重點」卡片有 AI 生成的每日摘要
3. **負載視圖** — 有按週的工作量分析，顏色分級
4. **優先度管理** — 有按 P0/P1 分級的全覽視圖

#### 盲點/斷點
1. **⚠️ 沒有里程碑 UI** — App 中沒有看到「里程碑」相關的建立或管理入口。Web 可能有 milestone-modal，但 Flutter App 完全沒有。這是影片腳本最大的問題：**影片宣稱的「里程碑建立→AI 排程」流程在 App 上不存在**。
2. **⚠️ 負載視圖是「按週」不是「按天」** — 影片設計的是 5 天長條圖熱力圖，但實際 UI 是週卡片展開模式，視覺差異很大。
3. **⚠️ 負載分級是「任務數」不是「小時」** — 圖例顯示 0-2/3-4/5-7/8+ 是任務數量，不是工時。影片設計的 6h/7h/10h 不符實際。
4. **每日計畫缺乏「Coach 建議」** — 首頁有 Coach briefing 卡片，但今日計畫本身沒有「建議你把某任務移到明天」這樣的 inline coaching。
5. **「維護中」狀態仍存在** — Memory 記載 MAINTAIN 已移除，但 task detail 的 status chips 仍顯示「維護中」。需要確認是否為 bug。
6. **沒有「完成率/準時率」統計概覽** — 影片 Scene4 設計的 87%/92% 統計數據，App 中沒有對應的 UI。

### 重大結論

**Brain Dump 影片**：素材充足，可以忠實重現 App 體驗。建議以實際截圖為基礎重做動畫。

**AI 排程影片**：**故事線需要大幅調整**。「里程碑」功能在 Flutter App 不存在，不能作為影片主軸。建議改為以下方向：
- 主軸改為「今日計畫 + AI Coach + 負載視圖」的組合
- 或改為展示 Web 端的里程碑功能（但這就不是 App 影片了）
- 最誠實的做法：這支影片暫緩，等里程碑功能在 App 上線後再製作

## Marionette MCP 操作筆記

### 連接方式
```
VM Service URI: ws://127.0.0.1:PORT/TOKEN/ws
```

### 注意事項
- Bottom sheet 關閉: 點擊背景遮罩區域 (例如 y:100 的區域)
- × 按鈕: 座標需精確，不要用截圖座標（截圖被縮放）
- TextField key: `capture_input` (Brain Dump 輸入框)
- 首次 AI 使用會跳 consent dialog，需點「同意並使用」
- 底部 nav 座標 (以 interactive elements 為準):
  - 今日: x:95, y:803
  - 總覽: x:163, y:803
  - 負載: x:213, y:803
  - 優先度: x:263, y:803
  - +: x:333, y:803
