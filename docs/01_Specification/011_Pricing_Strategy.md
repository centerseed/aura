
# Zentropy Pricing Strategy: The Entropy Series

**Version**: v1.0
**Philosophy**: Pricing based on **Order Magnitude** (秩序的量級).
我們不賣功能，我們賣的是從「基礎整理」到「系統化治理」的熵減能力。

---

## 1. Atom (原子) - Free Forever
**定位**: *The Fundamental Building Block.*
適合剛開始建立數位秩序的個人用戶。提供完整的核心體驗，但限制「流量」與「廣度」。

*   **Brain Dump**: 50 items / month. (足以養成習慣)
*   **AI Reorganization**: 10 times / month. (Project-level)
*   **Identity**: Single Area Only. (e.g., Only "Work" or "Life")
*   **Features**: 
    *   Basic Task Board (Inbox, Active, Maintain, Archive)
    *   Milestone Tracking
    *   Basic Vector Search

## 2. Fusion (融合) - ¥99 / Month
**定位**: *Unlimited Energy & Integration.*
適合依賴 Zentropy 作為主要大腦的高效工作者。移除所有阻力，並融合外部訊號。

*   **Brain Dump**: **Unlimited**.
*   **AI Reorganization**: **Unlimited**.
*   **Identity**: **Custom Areas** (Multiple Identities, e.g., Founder + Father + Creator).
*   **Vision Input**: Upload images/screenshots to create tasks.
*   **Signal Fusion (Integrations)**:
    *   **Slack**: Turn messages into tasks.
    *   **Google Calendar**: One-way sync (Tasks to Calendar).
    *   **Email**: Forward to Inbox.

## 3. Nexus (樞紐) - ¥199 / Month
**定位**: * The Central Hub of Your Ecosystem.*
適合 Power User 與團隊，Zentropy 成為連接內部協作與外部 AI 的中樞。

*   **Collaboration**: Shared Projects & Assignees.
*   **Headless MCP**: 
    *   Allow external agents (Cursor, Claude) to **read/write** your Zentropy context.
    *   `zentropy://` URI support.
*   **AI Scheduling**: Auto-schedule tasks into calendar slots based on energy/priority.
*   **API Access**: Personal API token for custom workflows.
*   **Priority Support**.
