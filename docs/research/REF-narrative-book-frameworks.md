## 二、各書核心框架

### 做自己的生命設計師（Designing Your Life）

| 框架 | 做什麼 |
|------|--------|
| **HWPL 儀表板** | Health/Work/Play/Love 四個油量表，自評現況 |
| **好時光日誌** | 每天記活動，標「能量」和「投入度」，三週後看模式 |
| **工作觀 + 人生觀羅盤** | 寫下你對工作和人生的信念，看是否一致 |
| **奧德賽計畫** | 畫三個不同的五年人生版本 |
| **原型測試** | 用最小成本去試，不是用想的 |
| **重力問題** | 不可改變的事就接受，不要浪費力氣 |
| **心智圖** | 從好時光日誌的高能量活動，快速發散聯想 |
| **失功能信念重擬** | 15 組常見錯誤信念 → 重新定義（如「熱情是結果不是原因」）|

**書的完整公式**：
儀表板（我在哪）→ 羅盤（我相信什麼）→ 好時光日誌（什麼給我能量）→ 心智圖（有什麼可能）→ 奧德賽計畫（我可以活什麼人生）→ 原型測試（去試）→ 選擇 → 迭代

### 停止無效努力

| 框架 | 做什麼 |
|------|--------|
| **冰山模型** | 知識/技能（表面）→ 能力 → 天賦/動機/價值觀（深層）|
| **SIGN 天賦識別** | S 自信 / I 本能衝動 / G 心流 / N 完成後的滿足感 |
| **學習區同心圓** | 舒適區 → 學習區 → 恐慌區，只在學習區練才有效 |
| **個人商業模式畫布** | 九宮格：我是誰、我能幫誰、我提供什麼價值 |
| **T 型人才** | 廣度 70 分 + 深度 90 分 |
| **問題分類四象限** | 解決度 × 關鍵度，避免掉入「無底洞」 |
| **結構化思維** | 自上而下找框架 / 自下而上歸納分組 |
| **情商五要素** | 自我意識、控制情緒、自我激勵、認知他人情緒、處理關係 |

**書的邏輯主線**：
認識自己（天賦）→ 裝備自己（學習+思維+溝通）→ 定位自己（平台選擇）→ 解放自己（破除定式+情緒管理）

### 發現天賦之旅（Finding Your Element）

| 框架 | 做什麼 |
|------|--------|
| **天命四元素** | 天賦 + 熱情 + 態度 + 機會 = Element |
| **智力三原則** | 多元性、動態性、獨特性 — 反對單一 IQ |
| **活動審計** | 列出每週活動，用顏色標記享受程度 |
| **族群（Tribe）** | 找到和你有共同天命的社群（肯定、引導、合作、綜效）|
| **三大障礙同心圓** | 個人障礙 → 社會障礙 → 文化障礙 |
| **導師四功能** | 識別、鼓勵、引導、拉伸 |
| **心流 = 天賦指標** | 做某件事時時間消失 = 你在對的地方 |
| **Pro-Am 概念** | 天命不一定是職業，業餘也能找到 Element |

**書的核心公式**：
Element = Aptitude（天賦）+ Passion（熱情），由 Attitude（態度）+ Opportunity（機會）啟動

### 高效原力（Feel-Good Productivity）

**三層結構（3×3）**：

| 層 | 主題 | 三個子框架 |
|----|------|-----------|
| **Energize 激勵** | 讓工作有活力 | Play（遊戲化）/ Power（自我賦權）/ People（人際能量）|
| **Unblock 解鎖** | 消除拖延 | Clarity（清晰度）/ Courage（勇氣）/ Getting Started（開始行動）|
| **Sustain 續航** | 避免倦怠 | Conserve（節能）/ Recharge（充電）/ Align（校準）|

| 框架 | 做什麼 |
|------|--------|
| **Play — 「如果很好玩會怎樣？」** | 8 種玩樂人格、支線任務、降低賭注 |
| **Power — 蝙蝠俠效應** | 創造一個勇敢的分身角色 |
| **NICE Goals** | Near-term / Input-based / Controllable / Energising（取代 SMART）|
| **生命之輪（9區3類）** | 身心靈 × 使命金錢成長 × 家愛友 |
| **能量投資組合** | 最多同時 5 個投入，Hell Yeah or No |
| **三種倦怠** | 過勞（Overexertion）/ 消耗（Depletion）/ 錯位（Misalignment）|
| **奧德賽計畫** | 同 DYL，三條五年路徑 |
| **CALM 充電框架** | Competence / Autonomy / Liberty / Mellow |
| **5 分鐘法則** | 只承諾做 5 分鐘，80% 會繼續 |

**書的核心翻轉**：
傳統：努力 → 成功 → 感覺好。Ali Abdaal：感覺好 → 生產力 → 成功。

## 三、四本書的共同主軸

### 共同信念 1：你的行動正在畫出你是誰，但你看不見

| 書 | 怎麼說 |
|----|--------|
| DYL | 好時光日誌：追蹤活動的能量/投入度，三週後才看得見模式 |
| 停止無效努力 | SIGN 模型：觀察你在哪些事上有本能衝動和心流 |
| 發現天賦 | 活動審計：列出每週活動，標記享受度 |
| 高效原力 | 能量投資組合：觀察什麼在給你能量、什麼在消耗你 |

**→ 自我認識靠觀察行動，不靠冥想反省。**

### 共同信念 2：人生有多個面向，失衡是最大的問題

| 書 | 分幾個面向 |
|----|-----------|
| DYL | 4：Health / Work / Play / Love |
| 停止無效努力 | 3：愉悅 / 成就 / 金錢 |
| 發現天賦 | 4：天賦 / 熱情 / 態度 / 機會 |
| 高效原力 | 9（3×3）：身心靈 × 使命金錢成長 × 家愛友 |

**→ 你需要一個多面向的儀表板來看全貌。**

### 共同信念 3：你以為重要的 ≠ 你實際在做的（錯位是最大敵人）

| 書 | 怎麼說 |
|----|--------|
| DYL | Workview / Lifeview coherence — 你的信念和行動是否一致？ |
| 停止無效努力 | 努力方向不對比不努力更糟 |
| 發現天賦 | 錯的環境會壓抑天賦（Gillian Lynne 故事）|
| 高效原力 | 錯位倦怠（misalignment burnout）— 最致命的一種倦怠 |

**→ 你需要一面鏡子，照出行動和信念的落差。**

### 共同信念 4：小步驟、累積、複利

| 書 | 怎麼說 |
|----|--------|
| DYL | 原型測試 — 用最小成本試 |
| 停止無效努力 | 刻意練習 — 在學習區反覆做 |
| 發現天賦 | 人生是有機的，不是線性的，走一步看一步 |
| 高效原力 | NICE Goals — 近期、投入導向、可控 |

### 共同信念 5：所有框架都卡在同一個地方 — 手動追蹤太累

| 書 | 要你做什麼 | 為什麼做不到 |
|----|-----------|-------------|
| DYL | 每天記好時光日誌 3 週 | 手動標能量值太累 |
| 停止無效努力 | 記日記觀察 SIGN | 要持續自我提問 |
| 發現天賦 | 活動審計 + 標顏色 | 做一次就不做了 |
| 高效原力 | 追蹤能量投資組合 | 誰會每天盤點？ |

**→ 框架都對，但執行需要持續的手動自我評估。人做不到。**

## 四、Zentropy 的戰略位置

四本書都在說同一句話：**觀察你的行動，就能認識你自己。**

但它們全都要求手動記錄和自我評估。

Zentropy 的定位：

> **你不需要寫日記、不需要自評、不需要填表。**
> **你只要管好你的事，Zentropy 從你做的每一件事裡，照出你正在成為的人。**

底層用的是這些書大家都認同的框架（生命之輪、能量追蹤、SIGN 心流指標、錯位偵測），但用戶不需要知道框架名——他們只需要看到結果。

### 可映射的產品能力

| 書的框架 | Zentropy 怎麼自動做到 |
|----------|---------------------|
| 好時光日誌（能量/投入追蹤）| AI 從任務內容自動判斷能量傾向 |
| SIGN 天賦識別 | 長期標籤累積 → 自動偵測心流領域 |
| 生命之輪 | Map Layer 自動從標籤分布畫出生活面向 |
| 活動審計 | 任務歷史 = 自動的活動紀錄 |
| 錯位偵測 | 用戶設定的價值觀 vs 實際任務分布 |
| 能量投資組合 | 自動計算各面向的投入密度 |
| 奧德賽計畫 | 基於現有模式，AI 推演不同路徑 |

## 五、Hero Page 敘事方向（待討論）

**A. 鏡子切角（錯位偵測）**
> 你每天在忙的事，和你真正在意的事，是同一件嗎？

**B. 自動觀察切角（取代手動日誌）**

> 你做的每一件事，都在決定你成為什麼人。

**D. 生命設計切角（借書名概念）**
> 做自己的生命設計師 — 這次 AI 幫你畫圖。
