# Skill 4: 情緒降壓除錯法 (Crisis Demolition)

## 目標受眾
面臨巨大壓力、專案嚴重卡關或停滯、產生逃避心理、甚至患有 ADHD 執行功能障礙的知識工作者。

## 觸發條件 (Trigger)
當用戶輸入涉及：
- 「我不知道怎麼開始...」
- 「這件事情拖了很久...」
- 「好焦慮...做不下去」
- 或由 Zentropy Coach 在背景**主動偵測**到某個 P0 專案處於死水狀態 (Stagnation) 超過一週，進而提問：「老闆，是否需要我幫您啟動降壓拆解模式？」

## 解決的痛點 (打破無知之幕)
當人們面對一個過於龐大且模糊的任務（例如：「寫一份 50 頁的商業計畫書」）時，大腦會將其標記為「不可能的威脅」，進而啟動逃避機制（如開始滑手機、整理桌面）。這就是拖延症的根源。
這個 Skill 強制打破這種恐懼，使用**「微結構化 (Micro-chunking)」**或**「奈米任務 (Nano-tasks)」**，將大任務剁碎到「微小到不可能失敗」的程度，藉此在心理學上重啟多巴胺的獎勵迴路 (Momentum Reignition)。

## 生成的任務結構 (Task Breakdown)
LLM (如 Claude) 必須保證，產出來的任務**第一條絕對不能超過 15 分鐘**。甚至只是要求用戶「打開某個軟體」而已。

### 【Phase 1: 奈米破冰 (Nano-Icebreaker)】
- 📍 **目的**：只求「開始」，不求完美。讓大腦體會到「勾選完成」的第一個快感。
- 📝 **任務清單範例 (假設是要寫下週的行銷簡報，但完全卡住)**：
  - [ ] 開一個空白的 Google Slides，或者隨便複製一個舊的模板。 (建議估時: 2m)
  - [ ] 在第一頁打上標題「下週行銷簡報」，底下署名自己的名字。 (建議估時: 1m)
  - [ ] 去找 3 張喜歡的競品廣告圖，截圖丟在桌面上的一個新資料夾裡。 (建議估時: 10m)

### 【Phase 2: 基礎雛形 (Ugly Draft)】
- 📍 **目的**：寫出最醜、最爛的第一版。允許自己搞砸。
- 📝 **任務清單範例**：
  - [ ] 不要管排版，在簡報裡把這三張截圖貼上去，旁邊打 3 句你覺得他們圖哪裡好看。 (建議估時: 15m)
  - [ ] 寫下我們自己的產品有哪三個賣點 (只寫關鍵字，不寫長句)。 (建議估時: 10m)

### 【Phase 3: 找回動能 (Momentum Regained)】
- 📍 **目的**：當你已經過了最痛苦的前 30 分鐘，大腦會自動進入流暢狀態 (Flow State)。接下來的任務可以稍微恢復正常大小。
- 📝 **任務清單範例**：
  - [ ] 把剛剛那 3 個賣點稍微擴寫成完整的段落。 (建議估時: 30m)
  - [ ] (如果今天真的很累，就標記此任務完成，明天再來進行後續的排版與潤飾)。

## 系統整合建議 (Config)
- **Coach 動能對齊**：The Coach 在背後是真正的功臣。當用戶完成【Phase 1】時，Coach 必須給予溫暖的回饋：「教練觀察到您已經勇敢地跨出了第一步！您已經成功克服最困難的部分了，要不要趁著手感，繼續把最醜的草稿寫出來？」
- **Zentropy 核心價值**：這是 Zentropy 作為「營運長」最性感、最具情緒價值 (Emotional Value) 的武器。
