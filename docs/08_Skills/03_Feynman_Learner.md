# Skill 3: 主題式知識重構器 (The Feynman Learner)

## 目標受眾
需要跨界學習新技能的人（如設計師學寫 Code，行銷人學爬蟲）、自學者、準備轉職者。

## 觸發條件 (Trigger)
當用戶輸入涉及：
- 「我要學會...」
- 「想在兩個月內上手...」
- 「我想懂...」

## 解決的痛點 (打破無知之幕)
現代人學習新事物最容易掉入的陷阱是「只看不練」，買了一堆線上課程或看了無數 YouTube，覺得自己好像懂了，實際上卻寫不出一行 code。或者是學習計畫排得太死板，淪為打卡機器。
本 Skill 利用**「費曼學習法 (Feynman Technique)」**與**「專案導向學習 (Project-Based Learning, PBL)」**的認知科學框架，將「學習」轉化為「可驗證的輸出任務」。

## 生成的任務結構 (Task Breakdown)
LLM 生成的不是「看第一章、看第二章」，而是要求用戶透過「吸收 ➔ 模仿 ➔ 實踐 ➔ 輸出」的心智挑戰：

### 【Phase 1: 吸收基礎與模仿 (Input & Imitation)】
- 📍 **目的**：獲取基礎知識，並透過「無腦跟著做」來建立自信心。
- 📝 **任務清單範例 (假設是學 Python 爬蟲)**：
  - [ ] 【吸收】用一週時間看懂 Python 的 `requests` 和 `BeautifulSoup` 的基礎觀念影片 (每天建議看 30 分鐘，共 5 天)。
  - [ ] 【模仿】跟著某篇 Tutorial (教學文)，一字不漏地照打一個「爬取天氣預報」的程式碼，並確定能在自己電腦上跑通。

### 【Phase 2: 實踐大挑戰 (Project Challenge)】
- 📍 **目的**：脫離舒適圈，也就是所謂的 Tutorial Hell (教學地獄)，嘗試獨立解決問題。
- 📝 **任務清單範例**：
  - [ ] 【挑戰】不看原來的範例碼，靠自己查官方文件或問 ChatGPT，寫出一個爬取「誠品暢銷排行榜前十名書名」的簡單腳本。 (建議時間: 3 天)
  - [ ] 【除錯】過程中把卡住超過 1 小時的 Error Message 記錄下來，建立自己的 Debug 筆記。

### 【Phase 3: 費曼輸出分享 (Feynman Output)】
- 📍 **目的**：透過最高難度的「教別人」，來驗證自己是否真正理解了這個概念。
- 📝 **任務清單範例**：
  - [ ] 【輸出】請想像要教一年班完全不懂程式的自己，寫出一篇 500 字的短筆記：「什麼是爬蟲，為什麼這兩行代碼可以抓到資料？」 (放在 Zentropy Note 中，或是分享到個人 Blog)。
  - [ ] 【優化】(進階) 把自己的腳本加上一個稍微複雜的功能 (例如：匯出成 CSV 檔)。

## 系統整合建議 (Config)
- **預設分類 (Area)**: 通常應放置於「Maintenance (維護區)」以確保細水長流，或當作每天的儀式。
- **Coach 動能對齊**：The Coach 會在打卡階段鼓勵微小的進步：「您已經連續三天看教學影片了！明天可以試試看進入 **【模仿】** 階段囉！」
