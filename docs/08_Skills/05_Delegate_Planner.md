# Skill 5: 一人公司外包指引 (Delegate Planner)

## 目標受眾
業務量爆炸的一人公司、正在準備擴張團隊的小老闆、不擅長委派任務的接案者。

## 觸發條件 (Trigger)
當用戶輸入涉及：
- 「我要辦一場 100 人的...」
- 「我要舉辦...但我只有一個人」
- 「要做...可是我不會設計/不會寫程式/沒有時間」
- 專案規模龐大，超出一人可負荷之極限。

## 解決的痛點 (打破無知之幕)
許多創業者或 Solo-founder 習慣「凡事親力親為 (Micromanagement)」，這不僅限制了公司的成長天花板，更會導致核心人物過勞崩潰。
他們需要的不是一個單純列出「一萬件事情」的清單，而是一份**具備管理思維的優先級分揀器**。
這個 Skill 利用**「老闆核心職責區 (Zone of Genius)」**與**「外包/自動化候選區」**的概念，強制創業者思考時間的投產比。

## 生成的任務結構 (Task Breakdown)
LLM 需要判斷哪些事情適合給人（或 AI）做，哪些事情只有老闆能做。

### 【類別 A: 你的天賦區 (Zone of Genius) - 必須親自做】
- 📍 **目的**：這些任務決定了這個專案的成敗、品牌調性、以及關鍵的人脈。
- 📝 **任務清單範例 (假設是要辦一場 100 人的實體論壇)**：
  - [ ] 確定本次論壇的核心主題論述，並決定要傳達給講者的品牌精神。(老闆專屬)
  - [ ] 以私人名義寄信邀約 3 位重量級產業講者。(老闆專屬，別人無法代勞)
  - [ ] 決定並控制本次活動的最高預算上限。(老闆專屬)

### 【類別 B: AI / 自動化候選區 (Automation & AI) - 電腦代勞】
- 📍 **目的**：繁瑣且高重複性的工作，應該交給不需要睡覺的軟體機器人。
- 📝 **任務清單範例**：
  - [ ] 註冊並設定活動報名系統 (如 Accupass 或 Typeform)。
  - [ ] 用 ChatGPT 協助草擬「活動報名頁文案」與「報名成功確認信」(草稿)。
  - [ ] 設定 Zapier 或 Make.com，當有人報名時，自動寄送電子發票與會前提醒。

### 【類別 C: 委外/發包候選區 (Outsourcing) - 花錢買時間】
- 📍 **目的**：非核心專長、或花費時間過多的低產值任務，請外部專家或兼職處理。
- 📝 **任務清單範例**：
  - [ ] 發包給設計師：設計本次活動的 Logo、講者名牌範本、以及入場的大型實體背板。 (建議去 Upwork/Fiverr 找)
  - [ ] 發包給工讀生：活動前一天的場地場勘、確認投影機與麥克風設備、訂購便當。 (請在社團或找大學生)
  - [ ] 聯絡活動當天的平面攝影師與錄影團隊。

## 系統整合建議 (Config)
- **Coach 動能對齊**：這將徹底改變任務的呈現方式。當這種計畫生成時，系統會自動幫任務加上 `@委外`、`@自動化` 等 Tag。
- **Coach 主動提醒**：當 Zentropy 發現老闆把 `@委外` 的任務拖了一週還沒發包出去，Coach 就會提醒：「老闆，『設計背板』這件事您是不打算發包自己畫了嗎？如果是的話，這可能佔用您最精華的時間喔！」
